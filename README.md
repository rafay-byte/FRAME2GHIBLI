## 📋 Overview

**Frame2Ghibli — Video-to-Ghibli Art Style Transfer** is a project by [Abdul Rafay Khalid (@rafay-byte)](https://github.com/rafay-byte).

Transform video frames into Studio Ghibli-style artwork using AI models (MeinaMix), with frame extraction, generation, and video reconstruction.

---

## ✨ Features

- 🎬 Video frame extraction
- 🎬 Ghibli-style art generation with AI
- 🎬 MeinaMix model integration
- 🎬 Video reconstruction from generated frames
- 🎬 Watermark-free output option

## 🚀 Getting Started

### Prerequisites

- **Python 3.8+** (or relevant runtime)
- **pip** package manager
- **Git** for version control

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rafay-byte/FRAME2GHIBLI.git
   cd FRAME2GHIBLI
   ```

2. **Create a virtual environment (recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate    # Linux/Mac
   venv\Scripts\activate       # Windows
   ```

### Usage

Refer to the project structure above and run the main script:
```bash
python app.py    # or the main entry point
```
